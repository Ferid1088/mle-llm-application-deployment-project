# Visual Assets

These illustrations support the project's architecture, containerization, and
capacity decisions. Keep the source attribution beside each use in the project
brief or README.

## Sources

- `containerization.png` is [Containerization](https://commons.wikimedia.org/wiki/File:Containerization.svg) from Wikimedia Commons. It is licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) and GFDL and attributed to MoreInput.
- `preble-architecture.png` is Figure 6 from the scientific paper [Preble: Efficient Distributed Prompt Scheduling for LLM Serving](https://arxiv.org/abs/2407.00023), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The figure shows a tokenizer, global scheduler, local schedulers, and model workers.
